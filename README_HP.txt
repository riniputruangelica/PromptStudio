BUILD APK DARI HP
1. Buat/login akun GitHub.
2. Buat repository baru, misalnya PromptStudio.
3. Ekstrak ZIP ini di HP.
4. Upload seluruh isi folder ke repository GitHub, termasuk folder .github/workflows.
5. Buka tab Actions.
6. Pilih "Build Prompt Studio APK".
7. Tekan "Run workflow".
8. Tunggu sampai selesai dan status hijau.
9. Buka hasil workflow dan download Artifact "Prompt-Studio-FREE-APK".
10. Ekstrak artifact lalu install app-debug.apk.

Jika GitHub meminta izin Actions, aktifkan Actions untuk repository.
