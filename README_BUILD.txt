PROMPT STUDIO FREE — ANDROID PROJECT
====================================

Ini adalah proyek Android native WebView yang membungkus aplikasi Prompt Studio FREE.
Aplikasi tidak memakai API AI berbayar.

Build:
1. Buka folder ini di Android Studio.
2. Tunggu Gradle Sync selesai.
3. Pilih Build > Build APK(s).
4. APK debug akan berada di app/build/outputs/apk/debug/.

Catatan:
- Lingkungan ChatGPT saat ini tidak menyediakan Android SDK/Gradle, jadi APK binary
  tidak dapat dikompilasi di sini.
- Project ini menggunakan Android Gradle Plugin 8.7.3 dan compileSdk 35.
- Untuk rilis Play Store, buat signing key/release build dan lengkapi metadata aplikasi.
